1.读取图像image，图像大小为752*480*3

2.图像灰度化Gray，图像大小为752*480：OpenCV中cvtColor函数可以实现： cvtColor(image,Gray,CV_BGR2GRAY)

3.图像降维为原来图像的1/4（180*120）为Gray_resize；opencv中resize函数实现：
resize(Gray, Gray_resize, Size(188, 120), 0, 0, INTER_LINEAR);

4.高斯滤波处理，高斯核子为5*5;；opencv中GaussianBlur函数可实现：GaussianBlur(Gray_resize, Img_Gauss, Size(5, 5), 0, 0 )

[Q]:这里应该进行模糊处理吗？
模糊处理后，找到的轮廓的数量变少了，可减少不必要的计算及干扰？

5.二值化阈值：计算ostu大津算法二值化的阈值thresholdValue。具体见以下链接：
https://www.cnblogs.com/mtcnn/p/9411987.html

6.二值化图像：函数threshold。threshold( Img_Gauss,BW,Th,255,CV_THRESH_BINARY)，Th为二值化的阈值，由于单一的阈值没有办法满足大部分的图像，二值化的阈值的扫描范围为Th=[thresholdValue,thresholdValue-3,thresholdValue+3,thresholdValue-6,thresholdValue+6,thresholdValue-9,thresholdValue+9,thresholdValue-12,thresholdValue+12,thresholdValue-15,thresholdValue+15,thresholdValue-18,thresholdValue+18,thresholdValue-50,thresholdValue+50,thresholdValue-80,thresholdValue+80]。
